= Manage SnapLock storage litigations
:imagesdir: ./media/

[.lead]
Use these endpoints to retain Compliance-mode WORM files for the duration of a litigation, ensuring indefinite retention as required. Legal holds are identified by a unique litigation ID, combining volume UUID and litigation name. This operation is reserved for users with the security login role vsadmin-snaplock.

Use this API to retain Compliance-mode WORM files for the duration of a litigation. A file under a legal-hold behaves as a WORM file with an indefinite retention period. Litigation ID is a combination of volume UUID and litigation name in the format `<volume UUID>:<litigation name>`. Only a user with the security login role vsadmin-snaplock can perform the operation.

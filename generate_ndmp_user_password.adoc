= Generate NDMP user password
:imagesdir: ./media/

[.lead]
Generate and retrieve NDMP user passwords for a specified Storage Virtual Machine (SVM) context to manage secure access within your ONTAP environment.

Generates and retrieves the password for a given NDMP user in the SVM context.

=== Examples

----
GET "/api/protocols/ndmp/svms/ca8e29e0-e116-11ea-876c-0050568ea754/passwords/ndmpuser"
----

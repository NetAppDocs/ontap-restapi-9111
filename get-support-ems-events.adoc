= Retrieve observed events

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/support/ems/events`#

*Introduced In:* 9.6

Retrieves a collection of observed events.

== Related ONTAP commands

* `event log show`

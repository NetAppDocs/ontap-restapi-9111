= Manage SVM peer relationships
:imagesdir: ./media/

[.lead]
Manage SVM peering relationships to create and oversee connections between Storage Virtual Machines (SVMs). Use these endpoints to facilitate collaboration and data sharing across different SVMs.

== Managing SVM peers

The SVM peer commands allow you to create and manage SVM peering relationships.

=== SVM peer APIs

The following APIs are used to manage SVM peers:

* GET /api/svm/peers
* POST /api/svm/peers
* GET /api/svm/peers/\{uuid}
* PATCH /api/svm/peers/\{uuid}
* DELETE /api/svm/peers/\{uuid}

= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Access and modify IPsec configuration settings to ensure secure data transmission within your network. Use these endpoints to retrieve current IPsec status or apply updates as needed.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec

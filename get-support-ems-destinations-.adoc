= Retrieve an event destination

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/support/ems/destinations/{name}`#

*Introduced In:* 9.6

Retrieves event destinations.

== Expensive properties

There is an added cost to retrieving values for these properties. They are not included by default in GET results and must be explicitly requested using the `fields` query parameter.

* `connectivity.+*+`

== Related ONTAP commands

* `event notification destination show`
* `event notification show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|name
|string
|path
|True
a|Destination name


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

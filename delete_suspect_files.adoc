= Delete suspect files
:imagesdir: ./media/

[.lead]
Use the suspects DELETE API to remove suspect files from a volume's list of potential threats. Employ these endpoints when you need to clear files that are flagged as suspicious to ensure system integrity.

The suspects DELETE API clears all the suspect files for a volume from the list of potential suspects.
